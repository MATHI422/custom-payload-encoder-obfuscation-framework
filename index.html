Custom Payload Encoder & Obfuscation Framework

A controlled cybersecurity laboratory project demonstrating how reversible text transformations affect a simple static signature matcher.

Techniques Implemented

Base64, ROT13, XOR, string reversal, separator insertion, escape-sequence representation, and character splitting.

Important Note

This demo uses harmless laboratory strings and a locally implemented detector. It does not interact with real malware or production security products.
